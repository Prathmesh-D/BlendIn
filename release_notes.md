# BlendIn v1.0.0 - Launch Release

Welcome to the official 1.0 release of BlendIn!

### What's New:
*   **AI Prompt Generator**: Instantly create brilliant custom packs by copying our specially crafted prompt and pasting your AI's response directly into the app. The engine auto-parses all words, decoys, and hints perfectly.
*   **Over-The-Air (OTA) Updates**: The app is now fully equipped to download UI and logic updates instantly on startup without requiring an App Store download.
*   **Manual Update Checks**: If you want to force an update check, head over to the Settings menu to use the new manual "Check for Updates" button.
*   **Refined UX**: Replaced raw, ugly inline text errors with sleek, brutalist pop-up dialogs that match the overall hacker aesthetic.
*   **Streamlined Gameplay**: Removed the bulky match history system to ensure zero friction between games.

This release includes the standalone Android APK.
